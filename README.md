# Auctioneer images

Artwork served to the [Auctioneer](https://github.com/Dubshott/pokemonauctiongame) Android app.
Kept in its own repository so the game repository stays small.

## yugioh/

Cropped Yu-Gi-Oh! card artwork, one file per card: `yugioh/<card id>.webp` (max 400 px).

Each image was downloaded once from the [YGOPRODeck API](https://ygoprodeck.com/api-guide/),
which asks apps to download and re-host images rather than hotlinking them. Cropped artwork
courtesy of YGOPRODeck and the Duelists Unite team.

Yu-Gi-Oh! card artwork is property of Konami. This fan project is not affiliated with or
endorsed by Konami.
